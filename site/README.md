# Medeo сайты

Дайын беттер (Astro + Tailwind), мини апптан бөлек. Дизайн — Figma «Medeo — Сайт» (28-құжат).

```
npm ci
npm run dev       # http://localhost:4321
npm run build     # dist/
```

- Тілдер: `/` — қазақша, `/ru/` — орысша. Мәтіндер: `src/i18n/kk.ts`, `src/i18n/ru.ts` (Figma-дан сөзбе-сөз).
- Түстер мен мәтін стильдері: `src/styles/global.css` (Figma айнымалылары: күндіз / түн). `.day` — түнде де күндізгі блок.
- Деректемелер мен байланыс: `src/config.ts` → `COMPANY`. `[тік жақшадағы]` мәндер әлі белгісіз.
- `PUBLIC_DEMO=0` — үлгі ұсыныстар мен пікірлерді жасырады. **Жарияламас бұрын міндетті** (нақты деректер API-ден келгенше).
- Шрифттер өз серверімізден (@fontsource, кириллица кеңейтілгені бар — қазақ әріптері).
